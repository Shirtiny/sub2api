# Presale opening email notification

Entry in subscription plan management. Admin can preview the next calendar-month notice, send a single test email, and explicitly confirm a sequential send to eligible users. Default audience has access; optional inclusion of restricted accounts and unapproved waitlist mailboxes. Sending never grants access or publishes plans. Preview includes presale-enabled draft plans if nothing is published, but broadcast requires payment enabled and published presale plans. Follow CafeShop letter styling and trusted configured frontend URL. Use a per-month mailbox receipt, atomic claim and explicit unknown-delivery state; never automatically resend after an ambiguous SMTP outcome. Respect optional-notification unsubscribe. Only the explicitly designated administrator mailbox is authorized for an actual sample. No production deployment, sale changes or bulk sending.
